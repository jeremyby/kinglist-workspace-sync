Privacy policy

King List Drive Sync is a personal synchronization utility operated by Jeremy. This policy describes the utility and its informational website.

Data accessed and purpose

With the owner's consent, rclone accesses Google Drive file and folder metadata, and file contents when needed for synchronization or verification. It uploads selected local project files to a configured private Drive folder and may update or trash destination items to reflect local changes.

The OAuth Drive permission may allow access beyond that folder. The utility is configured to target only the owner's designated mirror. It does not use broader access for unrelated purposes.

Storage and safeguards

Mirrored files are stored in the owner's Google Drive account. Original project files remain on the owner's private computer. OAuth credentials and refresh tokens are stored separately from public website content, with restricted local file access. Operational logs may contain file paths, timestamps, transfer sizes and errors.

The synchronization configuration is intended to exclude credentials, Git internals, installed dependencies and build caches. No filtering system is a substitute for reviewing what is uploaded. The mirror does not make project files publicly accessible.

Sharing and use

Google processes the mirrored data to provide Drive storage and API services. This informational website is hosted by GitHub Pages, whose infrastructure may process visitor IP addresses and request logs under GitHub's privacy statement. The pages contain no application analytics, advertising, cookies, forms or embedded third-party resources.

The utility does not sell Google user data, use it for advertising, or transfer it for training AI models. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention, revocation and deletion

The owner controls retention of project files, logs and Drive copies. Removing or changing local files may remove or overwrite their mirrored counterparts. Google Drive's own trash and retention rules also apply.

The owner can stop the utility and revoke its access through Google Account connections. Revoking access stops future authorized API access; it does not itself delete already uploaded files. Those can be removed directly in Drive. Local OAuth credentials and logs can be removed separately after stopping synchronization.

Contact and changes

Contact the operator through Jeremy's GitHub profile or the support email shown on the Google consent screen. Never send credentials or private files in public messages. Material changes to these practices will be reflected in this policy before the changed functionality is used.
